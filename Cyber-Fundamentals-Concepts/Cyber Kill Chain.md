# **Cyber 101: Cyber Kill Chain**

**Cyber Fundamentals**

## **What is the Cyber Kill Chain?**

The **Cyber Kill Chain** is a **step-by-step cybersecurity model** that describes the stages an attacker follows to carry out a cyberattack.

* Originally adapted by **Lockheed Martin**
* Based on a **military kill chain concept**
* Helps defenders **think like attackers**
* Used to **detect, disrupt, and prevent attacks** at early stages

---

## **Purpose of the Cyber Kill Chain**

* Understand attacker behavior
* Identify where an attack can be **stopped**
* Improve **defensive strategies**
* Support **incident response decisions**

---

## **The Seven Stages of the Cyber Kill Chain**

### **1) Reconnaissance**

* Attacker gathers information about the target
  **Examples:** scanning networks, collecting emails, researching systems

---

### **2) Weaponization**

* Attacker prepares the attack payload
  **Examples:** creating malware, exploiting known vulnerabilities

---

### **3) Delivery**

* Malware or malicious payload is delivered to the target
  **Examples:** phishing emails, malicious links, USB devices

---

### **4) Exploitation**

* Malicious code is executed
  **Examples:** exploiting software flaws, running malicious scripts

---

### **5) Installation**

* Attacker establishes persistence on the system
  **Examples:** installing backdoors, remote access tools

---

### **6) Command and Control (C2)**

* Attacker communicates with the compromised system
  **Examples:** remote control, data exfiltration

---

### **7) Actions on Objectives**

* Attacker achieves their goal
  **Examples:** data theft, ransomware deployment, system disruption

---

## **Why the Cyber Kill Chain is Important**

Organizations use it to:

* **Simulate attacks** (e.g., phishing tests)
* **Identify security gaps**
* **Evaluate defenses**
* **Fix vulnerabilities** before exploitation

---

## **Protection Against Attacks**

Using the Cyber Kill Chain, organizations can:

* Patch systems
* Train employees
* Deploy security tools (firewalls, VPNs, monitoring)
* Stop attacks **before they reach later stages**

---

## **Exam Tip**

If the question mentions:

* **Information gathering** → Reconnaissance
* **Preparing malware** → Weaponization
* **Sending payload** → Delivery
* **Running malicious code** → Exploitation
* **Maintaining access** → Installation
* **Remote control / data exfiltration** → Command and Control
* **Final goal achieved** → Actions on Objectives
